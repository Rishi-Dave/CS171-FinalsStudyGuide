## 🧠 Smart Features

### Smart Practice
- Automatically focuses on your weak topics
- Avoids recently seen questions
- Prioritizes your mistakes
- **Use this daily for best results!**

### Review Mistakes
- Shows only questions you got wrong
- Sorted by error frequency
- Perfect before exams
- **Requires some practice history first**

### Progress Dashboard
- Click "View Progress" button in header
- See weak topics (red), improving (yellow), mastered (green)
- Track all your sessions
- Export data anytime

---

## 📊 Understanding Your Progress

### Topic Colors
- 🔴 **Red (<60%)** → Practice MORE
- 🟡 **Yellow (60-80%)** → Keep practicing
- 🟢 **Green (>80%)** → You got this!

### Minimum Data
- Need **5+ attempts** per topic for categorization
- Take **2-3 exams** before using Smart Practice
- More data = better recommendations

---

## 💡 Study Strategy

### First Time Using App
1. Take "Full Exam" in Practice Mode
2. Review your answers with explanations
3. Check Progress Dashboard
4. Repeat 2-3 times

### Regular Practice
1. Daily: **Smart Practice** (30 min)
2. Weekly: Check Progress Dashboard
3. Focus: Topic-Specific on weak areas

### Before Exam
1. **Review Mistakes** mode
2. Full Exam (Timed Mode)
3. Check dashboard for confidence

---

## ⚙️ Settings

### Timed vs Untimed
- **Timed**: 90 minutes, real exam pressure
- **Untimed**: Learn at your pace

### Practice Mode (Checkbox)
- ✅ **ON**: Instant feedback after each answer (recommended for learning)
- ❌ **OFF**: See results only at end (for testing)

## 🔑 Keyboard Shortcuts
- **← →** : Previous/Next question
- **Ctrl/Cmd + F** : Flag question

## 📥 Data Management

### Export Progress
- Progress Dashboard → "Export Data"
- Saves JSON file with all your history
- Use for backup or transfer

### Reset Progress
- Progress Dashboard → "Reset Progress"
- Clears all tracking
- Use if starting fresh

## ❓ Quick Troubleshooting

| Issue | Solution |
|-------|----------|
| No progress showing | Complete and submit an exam first |
| "No mistakes found" | Take more exams to build history |
| Smart Practice random | Need 3-5 exams for good data |
| Progress disappeared | Using incognito? Export regularly! |
