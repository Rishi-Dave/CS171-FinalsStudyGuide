🚀 ALTERNATIVE SETUP (If needed):

   If double-clicking doesn't work, use a local server:

   OPTION A - Python (Easiest):
   
      cd path/to/ml-exam-simulator
      python3 -m http.server 8000
      
      Then visit: http://localhost:8000

   OPTION B - VS Code:
   
      1. Open folder in VS Code
      2. Install "Live Server" extension
      3. Right-click index.html → "Open with Live Server"

⚠️ TROUBLESHOOTING:

   Problem: Page looks broken
   Solution: Make sure all files are in correct folders
            Try using a local server (see above)

   Problem: Questions don't load
   Solution: Check browser console (F12)
            Refresh the page
            Try a different browser

   Problem: Timer not working
   Solution: Make sure JavaScript is enabled
            Try Chrome or Firefox
